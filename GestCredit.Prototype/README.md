# GestCredit - Prototype

Prototype console développé pendant la Semaine 1 de la montée en compétence Full-Stack .NET / Next.js.

## Contenu
- Menu principal avec gestion de saisie invalide
- Calculateur de mensualité de prêt
- Gestion d'une liste de clients en mémoire via LINQ

## Lancer le projet
```bash
dotnet run
```

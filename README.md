# GestCredit - Prototype (Semaine 1)

Prototype développé pendant la Semaine 1 de la montée en compétence Full-Stack .NET / Next.js.

## Structure
- `GestCredit.Prototype/` - Menu principal (Jour 1)
- `CalcMensualite.prototype/` - Calculateur de mensualité (Jour 2)
- `DetCategorie.Prototype/` - Calculateur refactorisé + catégorisation (Jour 3)
- `GestClient.Prototype/` - Gestion de clients en mémoire via LINQ (Jour 4)

## Lancer un projet

cd <NomDuDossier>
dotnet run
